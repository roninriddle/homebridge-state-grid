# homebridge-state-grid

当前版本：**0.7.0**。

把「网上国网」的用电数据做成 **HomeKit 虚拟摄像头**，在 Apple「家庭」App 首页直接看到一张用电卡片。

![紧凑卡片（浅色）](preview/compact-light.jpg)

不需要 Home Assistant、不需要 Python、不需要 Docker——纯 Node 进程，跟着 Homebridge 一起跑。

---

## 它长什么样

每个户号对应一路摄像头，默认名称为“国家电网”，多个户号可分别自定义名称。卡片顶部地区默认隐藏，可按户号开启。主数字为「账户余额/应交电费」，右侧并列「本月预估电费」，下方 4 列网格展示其余指标。插件内置 19 个指标：账户余额、本月预估电费、当月用电、上日用电、上日峰/谷/平/尖用电、当月峰/谷/平/尖用电、上月用电、上月电费、年累计用电、年累计电费、当前阶梯、违约金、历史欠费。显示哪些指标、按什么顺序，全都在设置页的「卡片指标」标签页里图形化配置（勾选显隐 + 上下排序），保存后几秒内自动生效，无需重启。数据每 6～24 小时刷新一次，卡片上的时间戳是最近一次成功查询的时间；日用电另标数据日期。接口只有部分日期且没有累计总量时，月用电明确标注“部分”。

| 浅色 | 深色 |
| --- | --- |
| ![](preview/compact-light.jpg) | ![](preview/compact-dark.jpg) |

数据取不到时，卡片显示 `—` 和「数据未更新」，**不把缺失值补成 0**；接口返回的真实零值会正常显示。

## 为什么是摄像头

| 方案 | 问题 |
| --- | --- |
| 温度/湿度传感器 | 只能表达一个数，HomeKit 没有"多指标"配件 |
| 自定义服务（Matter） | 家庭 App 里不渲染自定义字段 |
| **摄像头** | 快照即缩略图、点开即全屏，是最稳的"任意画面"载体 |

视频由 ffmpeg 根据 HomeKit 协商的地址、分辨率、码率和 payload type 输出 H.264/SRTP，并按实际时间限速。每个视频会话独立管理；无需外部媒体服务器。`src/camera/srtp.ts` 保留标准向量与独立互通验证使用的算法。

## 安装

```bash
npm install -g homebridge-state-grid
```

或在 Homebridge UI 的「插件」页搜索 `homebridge-state-grid`。

要求：**Node ≥ 22**（用到原生 `sm4-ecb` / `sm3`）、Homebridge ≥ 1.8。

## 配置

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| `username` | 网上国网手机号 | — |
| `password` | 登录密码（也只在首次登录时用，之后以设置页保存的为准） | — |
| `updateIntervalHours` | 刷新周期，范围 6～24 | `12` |
| `showRegion` | 卡片顶部是否显示省市区；支持按户号覆盖 | `false` |
| `theme` | 卡片主题 `light` / `dark` | `light` |
| `snapshotWidth` / `snapshotHeight` | 快照尺寸 | `1280` / `720` |
| `fields[]` | 卡片指标顺序（可选，作为回退默认；日常在设置页「卡片指标」标签页里图形化配置） | 12 项默认 |
| `accounts[]` | 户号级配置：`consNo`、`title`（摄像头名称）、`showRegion`、`enabled` | 全部启用 |

`consNo` 填接口返回的**原始户号**（`consNoSrc`）。在设置页「户号与卡片预览」标签页里能看到每个户号及其卡片预览，照抄即可。

`fields` 是一个**有序数组**，顺序即显示顺序：第 1 项是卡片主数字，第 2 项与它并列，其余进入下方 4 列网格。日常不需要手写——设置页「卡片指标」标签页里是图形化的勾选+排序界面（共 19 个指标，默认显示 12 个）。

## 首次登录

首次在新设备登录时，国家电网会要求短信验证。插件不做静默绕过，只把这一步交给设置页：

1. 插件设置页 → 填手机号 → **密码登录**，或点 **短信验证码登录**（无需密码）
2. 若返回 `4006`（新设备校验）→ **发送验证码** → 填入 6 位码 → **提交**
3. 登录成功后切到 **户号与卡片预览** 标签页查看户号与卡片；每个户号右上角有**启用开关**，关闭后主进程会在几秒内把该摄像头从「家庭」App 移除，无需重启
4. 保存设置 → 重启 Homebridge → 在「家庭」App 里添加 Homebridge

> 密码登录被拒绝可能涉及网关、限流或账号安全校验，不能仅凭 RK007 判定密码问题。可在设置页尝试短信登录；设备验证和额外安全挑战仍需按服务端要求完成。

设置页分三个标签页：**连接与登录**、**户号与卡片预览**、**卡片指标**。「户号与卡片预览」打开时默认读插件最近一次刷新落盘的缓存（户号列表、指标摘要、卡片预览图），**不重新联网**，因此不会反复触发国网的风控；只有点「刷新」按钮才向国网拉取最新数据。「卡片指标」里勾选并排序要显示的指标，右侧约 250ms 防抖实时预览。预览支持摄像头名称、地区显隐和指标顺序，只读本地缓存，不登录、不请求国网、不改正式配置；无缓存时明确标注模拟数据。切换标签页保留草稿，点击保存后主进程自动重新渲染正式卡片。名称与地区设置通过独立按钮保存；“保存指标”只应用指标顺序。预览主题仅用于查看效果，正式主题沿用插件配置。

登录态（token）与设备种子写在 `storage/state-grid/` 下，重启后沿用，不会重复要验证码。

> ⚠️ **不要手工删 `device.json`**。里面是设备指纹的种子，删了服务端就会认为换了一台手机，下一次登录又要短信验证。

## 工作原理

```
登录/查询  →  src/sgcc/     国密信封 + Turing V90 设备指纹（由上游 Python 逐字节翻译）
渲染      →  src/renderer/  SVG 排版 → resvg 栅格化成 PNG → ffmpeg 转 JPEG
出画面    →  src/camera/    ffmpeg 按协商参数、实际时间输出 H.264/SRTP
状态落地  →  src/services/  storage 目录：设备种子、会话、户号、卡片缓存
```

三处值得单独说明：

**1. 设备指纹必须稳定。** 32 字节种子经 HMAC-SHA256 派生机型、版本、传感器、性能上下文等全部设备特征；同一台机器上每次启动都必须得到同一份指纹，否则服务端判定为新设备。所以种子落盘、token 缓存 4 小时（对应 App 行为）。

**2. 协议正确性靠跨语言对拍。** `tools/gen-golden.py` 直接调用上游 Python 生成期望值，`tests/golden.test.ts` 逐字节比对 TS 实现——测试中有 17 项是这种黄金向量，涵盖 SM4/SM3/SM2 信封、64 位哈希、JCE 序列化、XXTEA、mode-0/1 token。

**3. 少一个原生依赖就少一半安装故障。** SVG 栅格化选 resvg（预编译二进制）而不是 node-canvas（cairo/pango）；PNG→JPEG 复用已有的 ffmpeg 而不是再引一个 JS 编码器。装不上的插件等于没写。

## 几条硬约定

- **缺失不补 0**：接口没返回就是 `undefined`，卡片渲染成 `—`。
- **估算必须标注**：本月电费用「上月实际均价 × 本月电量」反推，卡片上写「估算」，不冒充账单。
- **周期 6～24 小时**：接口不欢迎高频轮询，也不值得。
- **过期要说**：超过 26 小时没成功刷新，卡片标注「数据未更新 · 最近成功 …」。
- **保存的密码做明文遮蔽**：AES-256-GCM，沿用主机名、用户名和固定盐派生密钥以兼容旧安装。它不抵御已知主机信息的离线恢复；应保护 storage、config.json 和备份的访问权限。在 Homebridge 原始配置中填写的密码仍受其配置存储规则管理。

## 摄像头名称、地区显示与余额

- **默认名称是“国家电网”**，不使用户号、手机号或地区作为默认名称。多个户号可分别起名，如“自家用电”“父母家用电”。
- 设置页 → **卡片指标** → 选择户号 → 编辑“摄像头名称”，勾选或取消“显示卡片顶部的省市区” → **保存名称与地区显示**。草稿即时预览，保存后几秒内同步到摄像头和卡片，无需重启。
- **地区默认隐藏**。开启后，在名称下方单独显示省市区，过滤街道、门牌和脱敏星号；名称本身不会随地区开关改变。
- 也可用 `accounts[].title`、全局或单户号的 `showRegion` 配置默认值；设置页保存的户号设置优先。原配件 UUID 保持不变，无需重新配对。

![开启地区显示的模拟卡片](preview/region-visible.jpg)
- 明确返回预付费类型（`consType=1`）时，零余额和负余额也保留为「账户余额」；其他响应有预存余额时使用对应余额字段。各省字段仍需对照真实 App 校准，缺失值不会补零。

## 已知限制

- **省份差异**：日用电日期支持 `YYYYMMDD` 和 `YYYY-MM-DD`；月账单支持 `monthPq/monthAmt` 和嵌套 `eleList`；年度累计优先读取 `yearPq/yearAmt`。其他省份需逐项对照 App。默认日志不输出原始账户响应。
- **电费只是估算**：阶梯电价、峰谷、代扣优惠都没算。
- **户号多时首刷线性变慢**：每个户号要串行查日用电、余额、月账单。
- **登录风控**：复用设备种子和服务器会话，token 明确失效时最多自动重登一次；4006/RK008 进入人工验证。旧版猜测的 30 分钟有效期迁移为未知，下一次正常业务请求向服务端验证，不人为延长服务器 token 有效期。
- **字体**：macOS 使用系统中文字体；Linux 建议安装 Noto Sans CJK SC。resvg 不附带中文字体。
- **HomeKit 实机验收**：回环 SRTP 解码测试不能替代家庭 App 的首页、全屏、双客户端和远程访问验收。

## 开发

```bash
npm install
npm run build      # tsc，含类型检查
npm test           # 编译 + 黄金向量 / 会话 / 缓存 / 设置页 / 渲染回归
npm run test:stream # 回环双会话、独立 SRTP 解密与 ffmpeg 解码（需 ffmpeg）
npm run probe      # 设置页链路自测（不联网、不需要 Homebridge）
npm run demo       # 生成 preview/*.jpg 样张
```

如果 `tsc` 在受限环境里跑不起来（某些沙箱会拒绝它的大量文件探测），可以退一步只做转译：

```bash
node tools/build-esbuild.mjs
```

它不做类型检查，产出的模块形态与 tsc 一致，可以互相覆盖——**发版前仍然必须跑一次 `npm run build`**。

目录：

```
src/sgcc/        协议层（不依赖 Homebridge，可独立测试）
src/renderer/    SVG 卡片与栅格化
src/camera/      SRTP / RTP / 摄像头配件
src/services/    持久化与设备档案装配
src/platform.ts  Homebridge 平台（唯一接触 HomeKit 的地方）
homebridge-ui/   设置页（独立进程，经原子写的 storage 文件与主进程通信）
reference/       上游对照资料（不参与运行）
```
